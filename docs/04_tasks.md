# 開発工程（タスク一覧）

上から順に進める。終わったタスクは `- [x]` にする。工数は1日数時間の個人開発を想定した目安。
「関連機能」のIDは `02_function-design.md` を参照。

## 0. 準備（目安 2.5日）

- [ ] **0-1 開発環境の準備**：Node.js、エディタ、GitHub、AIコーディングツールを用意する（1日）
- [ ] **0-2 サービスのアカウント作成**：Supabase・Vercel・Google AI Studio（Gemini APIキー）のアカウントとプロジェクトを作成（前提：0-1／0.5日）
- [ ] **0-3 テスト素材の収集**：CAD図面・パンフレットのスキャン・手書きのフロア画像を各数枚と、店舗情報のサンプルExcelを用意する（1日）

## 1. 基盤づくり（目安 8日）

- [x] **1-1 プロジェクト作成とデプロイ**：Next.js＋TypeScriptのプロジェクトを作り、Vercelで公開できる状態にする（前提：0-2／1日）
- [ ] **1-2 DBテーブル作成と権限設定**：仕様書のテーブルを作成し、行単位の権限（RLS）で本人のマップだけ編集できるようにする（関連：全機能／前提：1-1／2日）
- [ ] **1-3 管理者登録・ログイン**：メール確認つきの登録とログイン。確認前はマップ作成不可（関連：F-01／前提：1-2／2日）
- [ ] **1-4 マップ一覧・作成**：マップの作成、マップコードの自動生成、初期ジャンルと建物1件の自動登録（関連：F-02／前提：1-3／2日）
- [ ] **1-5 利用上限チェック**：マップ作成・AI実行・画像アップロード前に上限を確認する共通処理（関連：F-15／前提：1-2／1日）

## 2. マップ編集（手動）（目安 10日）
