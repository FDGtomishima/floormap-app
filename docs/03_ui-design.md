# 画面デザイン

画面イメージはデザインキャンバス（claude.ai上の「フロアマップ 画面イメージ」）にある。ここには実装に必要な方針と値をまとめる。

## 方針

1. **直感的に操作できる**：タップできる部分は44px以上。管理画面は「マップ編集・店舗情報・公開設定」の3タブだけで行き来する
2. **色で分かる**：色の役割を固定する（下表）。ジャンル色は閲覧・管理で共通。色だけに頼らず、ジャンル名などの文字を必ず添える
3. **煩雑にしない**：閲覧画面のボタンは検索と言語切り替えだけ。店名は区画の中に表示し、ジャンルの凡例は絞り込みボタンを兼ねる

## フォント

- Noto Sans JP（400 / 500 / 700）、フォールバックは system-ui, sans-serif

### 区画の状態の表し方

| 状態 | 表し方 |
| --- | --- |
| 通常 | ジャンルの塗り＋1.5pxの枠 |
| 選択中 | 枠を3pxにする（管理画面は #2563EB） |
| 絞り込みで対象外 | 不透明度 0.25 |
| 番号未設定・店舗なし | #FFFBEB の塗り＋ #D97706 の2px点線 |

## 角丸・間隔

- 角丸：ボタン・入力欄 10〜14px、カード 14〜16px、区画 6px、チップ（ジャンル）は丸型
- 間隔は 4 の倍数（4 / 8 / 12 / 16 / 20 / 24）

## 閲覧画面（スマホ、幅390px基準）

上から順に：

1. ヘッダー（60px）：会場名、検索ボタン、言語切り替え
2. 建物の選択（建物が1つなら非表示）とフロアのタブ（セグメント形式）
3. ジャンルのチップ（横スクロール）。「すべて」＋各ジャンル。押すと絞り込み
4. マップ（残りの高さすべて）。右下に拡大・縮小・全体表示のボタン（44px）
5. 区画をタップすると、下から店舗詳細パネルが出る（背景は薄く暗くし、タップで閉じる）
   - 画像、ジャンルのラベル、建物・階・区画番号、店名、営業時間、紹介文、SNSリンクのボタン

### トップ（コード入力）

- アプリ名、説明文、マップコードの入力欄（大きめ、文字間隔を広く）、「マップを開く」ボタン、「カメラでQRコードを読み取る」ボタン
- 下部に「閲覧にログインは不要です」と管理者向けリンク

## 管理画面（PC、幅1280〜1440px基準）

共通：上にヘッダー（マップ名、「下書き：未公開の変更 N件」のバッジ、「スマホで確認」「公開する」ボタン）、その下にタブ（マップ編集／店舗情報／公開設定）。

### マップ編集

- 3列：左に建物・フロアの一覧（約240px）、中央に図面と区画、右に選択中の区画の設定（約320px）
- ツールバー：「選択」「区画を描く」の切り替え、「画像から自動作成（残り回数）」、「画像を差し替え」、拡大率
- 右の列：区画番号の入力と書式チェックの結果、紐づく店舗、削除ボタン、「確認が必要な区画」の一覧
- 図面の下に件数（区画数、番号未設定、書式の要確認）

### 店舗情報

- 見出し、件数、「取り込み用Excelのひな形」リンク、「Excelから取り込む」「店舗を追加」ボタン
- 取り込み後は確認バナー（新規・更新・エラーの件数、取り消す／N件を登録する）を表示し、確定するまで登録しない
- 検索欄、ジャンル・翻訳状況の絞り込み
- 一覧の列：区画番号、店名、ジャンル、営業時間、翻訳（英・简・繁）、取り込み結果、編集
  - エラー行は赤い背景とエラー内容
  - 翻訳の状態：緑＝AI翻訳済み、青＝手直し済み、灰色＝未翻訳

### 公開設定

- 左：「変更の公開」（未公開の変更点の一覧、「変更を公開する」ボタン、現在の公開版の日時）と「公開方法」（非公開／公開／期間限定のラジオ。期間限定なら開始・終了日時）
- 右：QRコード、マップコード、URL（コピー）、QRコードのダウンロード（PNG）
